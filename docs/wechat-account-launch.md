# 观澜微信公众号启动说明

## 账号定位

建议主账号名：

> 观澜ESG  
> 英文标识：ESG Compass

理由：

- 继续使用产品现有中英文品牌，不拆分已有认知。
- “观澜”有辨识度，“ESG”直接说明内容范围。
- `Sustainability Compass` 太长，`SustainCompass` 更像拼接词，搜索和口播都弱于现有品牌。
- `Sustainability Compass` 可以保留为账号说明中的正式英文描述，不承担主品牌作用。

注册时需要先尝试 `观澜ESG`。如果重名，优先使用 `观澜可持续`、`观澜ESG观察` 或 `观澜可持续观察`。

## 注册步骤

1. 打开微信公众平台 `https://mp.weixin.qq.com`，选择“立即注册”。
2. 选择“订阅号”。当前目标是持续发布 ESG 周报和文章，订阅号比服务号更合适。
3. 使用未注册过公众平台的邮箱完成激活。
4. 选择主体类型。个人主体流程更简单；机构主体便于后续认证、多人运营和更完整的账号能力，但需要相应组织材料。
5. 填写账号名称、功能介绍和头像。建议名称使用 `观澜ESG`，介绍中说明“每周梳理全球 ESG 政策、披露与资本市场变化”。
6. 完成身份或组织验证，按后台当前要求提交材料。
7. 审核通过后，设置运营者、自动回复、底部菜单和文章模板。
8. 账号可用后，在后台确认接口权限，再创建服务器端密钥与 IP 白名单。`AppID` 和 `AppSecret` 不应写入网页前端或公开仓库。

认证费用、接口权限和可调用范围可能调整，以注册后台当时显示的信息为准，不以第三方教程为准。

## 发布与推送不是同一件事

- 发表文章：素材进入公众号内容体系。
- 群发：向关注者主动推送，通常受账号类型和平台频率限制。
- 定时发表：公众号后台是否可用及时间选项以当前后台为准。
- 小程序订阅消息：必须由用户主动订阅，不能用来替代公众号文章群发。

因此，首发日应先在公众号后台完成草稿、预览和人工终审，再决定发表或群发。获得 API 权限后，可以把“生成草稿”和“请求人工审阅”自动化，但不应跳过人工确认直接群发。

## 微信矩阵推进顺序

1. 第一阶段：公众号每周一篇深度周报，先建立稳定更新和审阅流程。
2. 第二阶段：视频号把每周一个主议题压缩为 60 秒解读，为公众号导流。
3. 第三阶段：小程序提供实时浏览、主题筛选和收藏，公众号承担推送与深度解释。
4. 第四阶段：在内容量和留存稳定后，再评估社群、付费订阅或企业服务，不先堆渠道。

每周至少更新一次。建议固定为周一 08:00，遇到重大监管事件时可增加临时快讯，但不改变周报节奏。
