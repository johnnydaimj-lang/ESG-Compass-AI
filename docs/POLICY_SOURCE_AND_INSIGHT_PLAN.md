# 政策原文与解读关联方案

2026-11-19，本地实现；本批尚未推送。

## 产品判断

值得推进：发布机构原文负责确认政策事实，外部解读帮助理解影响和企业准备工作，符合 Compass 的专业、简洁定位。当前政策分类包含媒体报道与律所文章；仅将它们的链接称作“原文”会混淆来源层级。既有 sourceRefs 从文章提取外链，可能包含行业协会意见、企业页面等，也不等于已核验的发布机构原文。

不采用“同议题自动推荐解读”：它会重复上一版法规推荐的弱关联问题。编辑核验具体文档与文章分析位置有成本，首批先验证两个事项，不为数量扩展无证据关联，也不新增独立政策门户或首页栏目。

预期结果：用户在详情上方能直达发布机构具体文档，下方能分清外部分析是谁写、何时写、分析了什么。验收要求来源类型与日期清楚、不改旧快讯事实、无解读时不出现空栏目、默认最多三篇、转载不计为新进展。

## 页面顺序与边界

1. 原标题与快讯日期保持不变。
2. 已核验事项突出“发布机构原文”：机构、文档标题、类型、文号（若有）、原文发布日期与核验日。政府声明、咨询文件不标成已生效法规。
3. 来源文章另行归属，保留原媒体／律所署名和链接。未建立核验关联的事件只提供“阅读来源文章”，不猜测官方原文。
4. 摘要、事项进展、影响和企业自查保持现有路径。
5. 页面下方“相关解读与洞察”：机构、可核验作者、发布日期、一句分析角度、阅读解读；默认三篇，其余展开。机构署名文章不虚构个人作者。解读为第三方观点，不代表发布机构。
6. 与官方原文或解读重复的 sourceRefs 不再重复展示；剩余链接归“补充来源”。不使用旧 sourceRefs 的时间字段冒充原文发布日期。

普通转述报道、原文翻译、转载及只提及同议题的文章不作为解读。解读应有实质分析，例如适用范围、条款差异、实施准备、争议或情景影响，必须能定位对应原文或政策版本。解读只增加阅读材料，不新增事件节点，不改变快讯排序和精选评分。

## 复用现有事项数据

不另建政策关系数据库。在 `event-progress.json` version 1 的 matter 上扩展可选 `policy`：

- issuer / issuerHost：已人工核验的发布机构名称和文档承载域名；政府部门在议会发布的声明可使用议会官网。
- document：title、url、kind（法规原文／官方公告／立法声明／咨询文件）、可选 documentNumber、publishedOn、verifiedOn、evidenceLocator。
- insights：已入库 contentId、authors、angle、evidenceLocator、reviewedOn。

`resolvePolicyContext` 验证结构、HTTPS、精确承载域名、具体文档路径、真实日历日期与核验时点；这些检查不能替代人工核验机构身份和正文。解读必须继续通过 isFeedEligible，不能借引用绕过新闻评分。缺失证据、无效链接、未来核验日和未入库内容不展示；失败只隐藏 policy 部分，原事项进展继续工作。文章可从进展节点或明确解读关联找到同一事项；跨事项歧义不任意选取。

`sourceKey` 仅去掉跟踪参数与锚点，保留识别不同文档的功能查询参数；官方链接、当前来源和解读按此去重。`PolicySource` 与 `PolicyInsights` 为服务端组件，不增加首页传输数据或客户端关联计算。公开 API 暂不添加 policy 字段。

## 溯源流程修正与后续追踪

`trace:upstream` 继续只提取候选，不自动授予“官方”或“解读”身份。PDF 可以是正式政策文件，不再当作图片等资源过滤；不再把新闻发布时间写入新候选链接的 publishedAt。URL 去重保留功能查询参数。旧记录不批量重写，界面不依赖其日期。

首批人工核验并关联两个现有事项：

- 英国人权尽职调查：政府 [HCWS454 声明](https://questions-statements.parliament.uk/written-statements/detail/2026-11-04/HCWS454)（2026-11-04）与已入库的 [Skadden 解读](https://www.skadden.com/insights/publications/2026/11/uk-government-to-introduce-mandatory-human-rights-due-diligence-regime)（2026-11-09）；开头明确链接声明，Next Steps 段落提供企业准备分析，作者四人可核验。
- 欧盟有限鉴证标准：[官方咨询页](https://finance.ec.europa.eu/regulation-and-supervision/consultations-0/targeted-consultation-limited-assurance-standard_en)（2026-11-12），Details、Why we are consulting 和 Reference documents 确认具体咨询及文件。当前已入库条目是新闻转述，不强行作为解读展示。

本批实现的是文档级溯源与已收录解读关联，没有新增定时爬虫或宣称原文实时监控。后续采集应以发布机构文档标识和版本为锚，官方修订、正式发布、撤回等事实仍经现有评分、聚类及审核后入库；媒体解读不触发政策阶段变化。原文版本变化后，应复核旧解读对应版本及适用性，再设计自动变更检测。全量回填、全文存档和政策适用判断不在本批范围。

## 全产品执行规范（用户确认）

上述原则统一适用于后续新增内容、存量补齐、详情及知识专区；企业事件同样区分当事方披露、监管依据和外部分析。不增加首页复杂度，不将媒体或律所内容删除出采集范围；它们继续承担线索发现和影响分析价值，但不能顶替官方来源。

AI 共用 `source-evidence` 规则，区分文件版本、政策阶段、日期类型和观点归属。高等级来源不等于事件当事方，确定性理解在缺乏作者证据时保守标 relayer；启发式分类与聚类不授予官方核验身份。现有两个人工核验事项保持为首批覆盖，整体采用规范不代表已完成全量原文监测或历史回填。
