# 气候披露底稿最小实施规格

状态：待开发；2026-11-18根据[跨市场样本](CLIMATE_DISCLOSURE_BENCHMARKS.md)修订。此规格细化原[市场与披露方案](CLIMATE_MARKET_AND_DISCLOSURE_REVIEW.md)，不宣称功能已经上线。

## 预期成果及边界

企业用户在现有实验结果之后，用三步形成可修改、可复核的气候分析章节草稿：企业边界与期限 → 风险/机遇及依据 → 预览与导出。首期不建设报告管理后台、企业档案或批量资产组合。完整ISSB/GRI披露、行业工程评估、概率损失和会计估值不在本批范围。

成功标准：没有完整量化模型的用户也能形成清楚的定性底稿；有可靠财务输入时能做部分量化；缺证据时保留空缺；任何数值、比例和叙述都能回到来源或确定性计算，不让AI补造公司事实。

## 三步交互

| 步骤 | 默认可见 | 按需展开 | 完成状态 |
| --- | --- | --- | --- |
| 1 企业边界与期限 | 报告主体、期间、业务模式、分析范围与适用标准版本 | 资产寿命/持有期、短中长期定义与理由、价值链覆盖 | 已填/待确认/缺证据 |
| 2 风险和情景 | 从当前实验带入风险与路径，增加一条有依据的对照路径；说明选择理由；核对经营依赖和措施 | 原文、数据覆盖、来源版本、财务输入、重要性阈值 | 定性/部分量化/缺数据 |
| 3 结果与导出 | 风险表、情景比较、叙述、缺口及复核状态 | 完整假设与证据清单、人工改动和方法说明 | 草稿/已企业复核；不提供“已合规”状态 |

每步一个主操作；返回修改不丢数据。采用详情展开而非大表单。初版可先在浏览器本地维护，刷新丢失前提示下载；不默认上传财务资料。必须允许仅定性输出，不把所有金额字段设为必填。

情景比较需限定同一危险/经营链、主体范围、单位和指标定义；IPCC与IEA/NGFS之间不按温升自动建立数值映射。当前没有真实路径数据时可以比较有依据的叙事，但不能声称官方情景已经自动改变财务数值。允许明确标识的用户条件假设，不能用默认值冒充企业实测。

## 输出表和核心字段

默认结果表：风险/机遇｜情景与期限｜经营影响｜财务影响方向/指标｜应对与措施状态｜依据及缺口。金额可选；财务金额和比例使用同一已确认分母。历史事件作为参考链接单独放置，不被生成器作为本企业事实。

在原七组底稿契约基础上，补充以下强约束：

| 字段 | 含义及约束 |
| --- | --- |
| `metricKind` | hazard / exposure / conditional-impact / expected-loss / valuation-sensitivity；首期只接前三类有验证的结果 |
| `effectStatus` | historical-actual / anticipated / conditional；不可在导出时混写 |
| `affectedParty` | 本企业、客户、供应商或其他主体；CBAM进口商等成本不能直接归入本企业损益 |
| `periodBasis` | 单次、单年、年均、多年累计、折现现值；缺定义时禁出金额结论 |
| `denominator` | 营收/资产等比例分母的值、期间、范围、来源；无分母不计算占比 |
| `managementCase` | 无新增措施 / 已实施措施 / 已批准计划 / 假设措施；实际成效不能由措施名称推定 |
| `costBoundary` | 实施成本、维护费、保险、税、恢复收入、成本转嫁是否计入；逐项用 included/excluded/unknown |
| `baseline` | 比较基线与基年；基线不是自动零损失 |
| `scenarioReference` | 机构、文档版本、路径、模型、分析窗口；替代数据需proxy理由与限制 |
| `materialityBasis` | 企业自行确认的阈值、尺度和理由；缺失为待判断，不自动套用太古/BASF阈值 |
| `evidenceRef` | 原始URL/附件、页码/题号、读取方式、核对日、许可、可用时的哈希；索引摘录标识不得隐藏 |
| `changeRecord` | 相比上版的边界、情景和假设变化；变更使旧复核失效 |

定性影响采用方向和事实链，不用默认概率或损失率。方向可为增加、减少、方向未定；程度只有企业定义了尺度并确认后才展示，定义随导出保留。

## 定量接入规则

1. 现有经营冲击和碳成本纯函数输出仅标为条件敏感性；用户确认金额口径、假设来源与情景关系后才纳入草稿。未验证默认教学值保持示例状态。
2. 真实高温天数是危险度指标，不直接转停工、人员健康损失或财务结果；当地点无覆盖时，草稿显示缺口。
3. 同类金额允许在相同假设下对比；比例显示分母。单次经营差额未计全寿命成本，不能叫净现值、年均收益或避免损失预测。
4. 风险降低与措施成本分别列示；若措施成本未计入，明确写“仅比较风险成本，不代表整体净收益”。
5. 首期不支持事件概率、期望损失、累计DCF、公允价值或贷款ECL。未来接入须另有数据、行业函数、校准/回测与独立复算验收。

## 生成、复核与导出

先确定性生成结构化表和计算摘要，再由模板生成中文草稿；首期模板即可，不强依赖LLM。后续LLM只作有证据的语言组织，接收显式数据对象，不能根据企业名称、网络范文或外部公司比例自动填值。

叙述按“范围与方法—情景选择—风险/机遇传导—可能财务影响—措施与局限”组织。ISSB财务影响与GRI人和环境影响分别映射，需验证适用版本及企业重大性；它们不是同一段万能文字。输出不保证符合任一完整标准。

导出Markdown叙述、CSV表格、JSON证据与假设包。每条句子/表行绑定证据或计算ID；输入未知显示待确认，缺少资料也允许下载明确标记的草稿。企业复核覆盖事实、措施及判断，但不把点击确认称作审计或鉴证。

文档研究索引属于只读参考数据，不在公开事件API中暴露，也不自动参与AI评分。企业输入与研究样本严格分开；未来服务器存储须另行实现身份授权、租户隔离、保存期和删除机制，首期无公共写接口。

## 开发批次

1. **D1：契约与模板。** 定性风险表、来源/缺口、中文叙述及JSON/CSV/Markdown序列化；纯函数，无外网或AI调用。
2. **D2：友好交互。** 现有实验结果后的单一入口与三步编辑、预览、导出；保留返回修改及输入未确认状态，不先建设后台。
3. **D3：部分量化。** 接现有已测试计算，增加主体、期间、分母与成本边界校验；借鉴企业样本布局，不复制其系数。
4. **D4：企业试用。** 用获授权企业事实验证可读性、填写负担和财务复核，针对缺口调整，不用虚拟样本宣称完成外部披露。

## 最低验收

- 主体、期间、范围或情景理由缺失时，结果明确为未完成草稿。
- 没有企业事实，不生成已实施措施、董事会批准、量化金额、韧性结论或合规声明。
- 未知、无覆盖、不适用和零分开；无金额也能导出定性表。
- 敞口、损失、预计损失、DCF不能互换名称；单次和年度不能相加。
- 客户/供应商成本不能直接归到本企业；比例分母不一致时不比较。
- 未来恢复计划不能写成已实现，未来分析不成为历史事件。
- 示例默认值不能不经确认混入企业底稿；因缺数据而使用代理变量须给理由。
- 修改任何相关输入、边界或情景后旧复核失效；相同输入与版本的导出可复现。
- Markdown/CSV/JSON导出保持证据ID、金额口径和缺口一致；CSV文本以安全方式处理公式前缀。
- 390px移动端及键盘操作可用，三步返回不丢数据；导出不泄露到公开日志/API。
