# 事项进展交互与技术方案

2026-11-19，首批实现；尚未推送线上。

## 取舍与验收

用户需要快速判断变化及企业可采取的检查行动。首页已有足够入口，本次保留 ESG 快讯布局、卡片、筛选、排序和精选机制；不增加横幅、消息中心、关注按钮或新增进展数量角标。

事件详情承担理解进展的主要任务，知识专区提供入口。比另建独立事项页面更轻量，也避免维护两套时间线。维护成本主要在事项关联和节点事实核对；词面聚类容易误合并不同政策，故不自动生成进展。

验收：原快讯标题、发布日期和摘要不被覆盖；同一事项入口共用一个查询结果；只有合格内容可公开；转载、补充评论不计为节点；最多默认展示三个节点；单节点不展示空时间线；不将咨询截止日或拟实施日当作已发生进展。

## 页面与状态

- ESG 快讯：本批没有改动首页代码，现有事件详情入口保持原样。未来是否增加轻量提示须单独验证，不默认增加标记。
- 有事项关联的事件：原摘要下显示事项名称、收录阶段、最新变化、报道覆盖时间及企业自查问题。页面标题和日期始终对应本条快讯。
- 两个及以上有效节点：按事件日期倒序，缺少事件日期时用明确标注的报道日期；显示最近三个，其余原生 details 展开。每节点连接原文和当时快讯，标记本条快讯。
- 一个节点：展示阶段及证据，不展示时间线；无有效关联：不占空间。
- 其他相关报道：折叠阅读，明确不计为新进展。热度趋势默认折叠。按同议题派生的法规与标准推荐已移除，避免把主题相似误作实质关联。
- 知识专区：在现有地图上方列出明确关联的事项，默认五项，更多折叠；点击最新有效节点的 `/events/{id}#event-progress`。同一事项可以属于多个专区。原地图与地区法规继续保留。

## 单一数据来源

新增可选快照 `data/publication/event-progress.json`，schema version 1：

- matters：id、title、region、zoneIds、selfChecks、entries。
- entry：稳定节点 id、已发布 contentId、stage、change，以及可选 occurredOn（实际发生日期，YYYY-MM-DD）。
- organizedAt / evidenceScope：本批整理时间和证据范围说明。

正文、来源链接、报道日期均由 contentId 在发布快照中解析，不复制新闻正文。`event-progress-store.ts` 供详情和专区共用，`event-progress.ts` 为可测试的纯解析层。快照缺失、错误或版本不支持时不显示模块；不触发实时采集。publication bundle 写入流程不覆盖此人工维护文件。

解析先检查 schema、isFeedEligible、日期、重复节点、重复内容和重复原文地址，再稳定排序；不同事项抢占同一内容时隐藏冲突事项，等待纠正。未来日期或不可能日期不能用作事件日期。公共详情也执行 isFeedEligible，低分或不合格内容返回 404，元数据不泄漏标题。

## 编辑与运营边界

1. 原始内容必须走既有采集、评分和发布门槛，本模块不提供绕过入库途径。
2. 编辑先确认是同一事项，再确认出现实质事实变化。相同公告的转载、补充解释并为原节点证据，不另算里程碑；sourceRefs 和 storyId 不等于进展。
3. stage 必须依据相应报道的时点措辞，例如宣布立法计划、草案咨询；不把“提出、拟议、表决推动”改写成“生效”。
4. occurredOn 仅填写已知实际事件日期，不从报道日期倒推，不填写咨询截止或未来生效日。
5. 企业自查使用条件式表达；不宣称该用户企业已经适用该政策。不是精选推荐理由，不更改 recommendReason。
6. 改动后运行 typecheck、test 和 build；发布时连同引用内容及文档一起检查。失效内容引用自动消失，不回退低质量内容。

首批两项：英国人权尽职调查立法计划、欧盟可持续报告鉴证准则咨询，均为单节点，初始依据已发布摘要整理。后续“发布机构原文与解读”优化已核验英国 HCWS454 政府声明、欧盟官方咨询页及 Skadden 具体解读，并在事项上增加可选 policy 关联；仍不声称完成完整政策历史或实时法律状态核验。相同英国公告的另一篇报道没有新增节点。多节点交互已由五节点测试覆盖，真实后续节点应在新事实入库后补充。证据与数据契约见 `POLICY_SOURCE_AND_INSIGHT_PLAN.md`。

## 本批不包含

不改变首页 story collapse、评分和推荐策略，不建设企业档案、趋势统计或风险提醒。自动进展识别、全量历史回填、全文法律核验及公开 API 的进展字段暂未实现。原地区法规地图中的历史说明不因本模块自动成为经过更新核验的当前规则。

## 事件法规关联修订（2026-11-19）

移除事件页的法规候选查询及列表，主题探索通过所属专区继续。原因是原规则按宽泛专区关键词匹配并取最新政策，不验证具体法律联系；提高相似度阈值或缩短列表仍不能证明适用义务，另建 AI 关联评分又增加核验成本。本批选择直接删去冗余模块。

如后续验证用户确需直接法规引用，应限定明确原文引用、处罚依据或经核实适用义务三类关系，保留证据位置、原文链接与一句关联说明，无可靠证据不显示。不得把政策新闻当作标准原文，不得由行业／地区猜测适用性。该引用机制与数据回填留待后续验证，不在当前实现中预留空 UI 或新配置。
