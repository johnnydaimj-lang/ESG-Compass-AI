# 高温投影参考数据

此目录保存NASA NEX-GDDP-CMIP6原始点位子集和经过校验的派生结果。不是实时天气或企业资产损失数据。

- 数据集：NEX-GDDP-CMIP6，分片v2.0。
- 模型/成员：ACCESS-CM2 / r1i1p1f1；变量tasmax（K）。
- 历史：1995–2014；未来：2041–2060。
- 情景：ssp126、ssp245、ssp585；上海与鹿特丹参考网格。
- 指标：每个完整公历年内tasmax − 273.15 > 35的天数，再对20年取算术平均。
- 许可：CC0，见https://registry.opendata.aws/nex-gddp-cmip6/，保留来源归属。

## 文件

heat-snapshot.json：只读API读取的校验后快照。目标六条记录，当前仅上海ssp126/ssp245两条完整；不能把共享的历史基准当作额外模型样本。

heat-evidence-manifest.json：已保存CSV的原始请求URL、SHA256和真实采集时间（目标160份，当前81份）。

evidence/*.csv：每份一个点位、一个情景、一个完整年份；.meta.json为断点续传校验元数据。用于离线复算，不发送到浏览器。

## 更新

运行npm run climate:collect，再运行npm run climate:verify。采集最多四并发，每请求90秒，普通失败最多三次并退避；429/503熔断停止新增请求。缓存须URL与哈希一致才能复用。仅发布完整40年组合并保留已有组合；--cache-only可从已有证据生成部分预览，不联网。运行npm run climate:verify -- --require-full检查目标160份证据/6条完整记录，当前因源服务故障尚不能通过。

collection-status.json记录实际完整窗口和未完成组合。2026-11-18原始服务发生503和健康检查超时；部分预览不代表完整阶段B验收。

完整性：检查公历天数（含闰日）、逐日连续且唯一、单位K、缺测及合理数值、同年同网格、历史与未来同模型和格点。NASA服务200响应并不代表数据有效。

## 使用边界

仅支持已验证格点和窗口。单模型结果未量化跨模型不确定性；柱图的年际变化不是置信区间。35°C不是通用安全或停工阈值；不能据此预测工伤、停工或货币损失。历史基准是气候模型模拟，不是观测。没有已校准损失函数，不能输出预期年损失或公允价值。
