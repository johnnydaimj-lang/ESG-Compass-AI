# 员工 2 号：选题区

每个候选选题一个 JSON 文件，建议命名为 `{candidateKey}.json`。

候选来自 ESG Compass 产品内容，不来自 W43 或旧版周报信号。

必须包含：

- `candidateKey`
- `status`：`shortlisted` / `selected` / `researching` / `rejected`
- `editorialLine`：`hotspot` / `research`
- `workingTitle`
- `productItemIds`
- `storyIds`
- `sourceUrls`
- `eventFact`
- `controversy`
- `thesis`
- `whyNow`
- `targetReader`
- `evidenceAvailable`
- `evidenceGaps`
- `riskLevel`
- `risks`
- `scores`
- `createdAt`
- `updatedAt`

每轮建议写 2-3 个候选。只有 Johnny 明确选定后，才把状态改为 `selected` 并开始正式研究。

爆款潜力不能替代证据质量。候选必须说明真正的事件事实、争议点、证据缺口和合规风险。
